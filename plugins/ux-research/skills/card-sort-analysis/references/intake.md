# Intake

The questions the skill asks before analysing, in order. Stop as soon as you have what the next
step needs, and never re-ask something the user has already said.

**Last updated:** 21 October 2026

---

## The questions

1. **Which tool did you run the card sort in?** Needed to load the right profile from
   `references/tools/`. If it is not listed, use `tools/_generic.md`.
2. **Was it an open, closed or hybrid sort?** In an open sort participants name their own groups.
   In a closed sort the categories are supplied. In a hybrid sort both happen.
3. **What can you share?**
   - an export (CSV or Excel),
   - screenshots of the tool's similarity matrix and dendrogram,
   - or both.

   This decides the route: data, image or combined. Say which route you will take and why.
4. **How many participants, and how many cards?** Read it from the data if you can, and confirm.
5. **What decision will the results feed?** For example "choose the top-level navigation" or "decide
   whether to merge two sections". The report answers the decision rather than describing
   everything the data holds.
6. **Who are the participants?** Whether they are one user group or several matters, because
   disagreement may follow user types, and each type needs enough people to analyse alone.
7. **Anything unusual about the sort?** Cards that were reworded, categories added mid-study,
   participants excluded already, or a setting such as "continue without sorting every card".

## What to say when something is unknown

- **The user does not know how the tool treats unsorted cards.** That is normal, because almost no
  tool documents it. Ask what the export shows for a card someone left unsorted, or treat it as a
  setting to choose (`singleton` is the script's default) and report which was used.
- **The user cannot say what the dendrogram's axis means.** Ask them to open the tool's legend or
  help, or to screenshot the axis. If nothing documents it, say the axis is unknown and do not read
  heights as percentages.
- **The user cannot share an export.** Use the image route, and say plainly that findings from
  screenshots carry lower confidence.

## Provisional and unverified profiles

If the tool is Playbook UX, UserTesting, UserZoom or Useberry, tell the user the profile is
provisional or unverified and that their own file takes priority over it. Ask for a small export or
the column headers before relying on any layout.
