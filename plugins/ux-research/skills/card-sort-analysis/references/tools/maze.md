## Sort types

Open and closed. **Hybrid is not supported.** Plan gating conflicts between pages: one page says
closed sorts are on all paid plans and open sorts on Team and Enterprise, and another says open card
sorting is on the Enterprise plan. `(verified, as a conflict)` Check what the user has.

There is no hard limit on cards or categories, and you can cap the number of cards per category. A
setting lets participants continue without sorting every card.

## Views

| View | Notes |
|---|---|
| Cards and categories tab | Average agreement, single-card agreement rate and frequency per card or category. Agreement rate is (count in category x 100) / total participants. |
| Raw results toggle | Open sorts. Categories with identical names are combined automatically by default. |
| Agreement matrix | Groups cards under each category by their highest agreement rates. |
| Similarity matrix | The percentage of participants who put a pair together, (count in pairing x 100) / total participant count. It can be shown or hidden in the PDF report. |
| Dendrogram | **Not mentioned in any page read.** |
| Participant-level view | **Not found.** |

`(verified)`. Minimums in the help centre: 10 unmoderated or 5 moderated participants (a vendor
figure).

## Export

- **Whole-study CSV.** Paid plans only. Settings, then Export, then CSV.
- **Per-block CSV.** From the results dashboard, select the block, then download. **Maze recommends
  this over the whole-study export.**
- **PDF** of the auto-generated report only.
- An August 2024 changelog says metadata fields each have a column and timestamps are YYYY-MM-DD.
  Card sorting is not mentioned.
- **The card sort CSV layout is not documented:** columns, what a row is, how categories, unsorted
  cards and participant IDs appear. A secondary summary said it includes a Maze ID and a Tester ID
  `(unverified)`.
- **No documented export of the similarity or agreement matrix as data.**
- Only owners, admins and editors can export `(unverified, third-party)`.

`(verified)` except where marked.

## Route

**Combined or image.** Ask for the per-block CSV and map it. If it holds per-participant sorts,
compute from it. Read the agreement and similarity matrices from screenshots, and ask for hover
values if they show shading only. There is no tool dendrogram to read, so the computed one is the
only one, and the report should say so.
